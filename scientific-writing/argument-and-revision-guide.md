<a name="section-2"></a>

## Build an argument

State the question → propose a bounded claim → present located evidence → explain the inference → examine alternatives → state limitations and implications. Avoid using a citation as a substitute for explaining why the evidence supports the conclusion.

<a name="section-3"></a>

## Citation management without a required plugin

Keep one stable citation key in each primary-paper note, along with verified authors, title, year, venue, identifier, version, and access limits. Reuse that key consistently in draft citations and the manuscript reference list. Record page/figure/equation locators in evidence notes. Check every final reference against the source, including corrections or retractions when known. No reference-manager integration is required or configured by this implementation.

<a name="section-4"></a>

## Common revision problems

| Problem | Revision action |
| --- | --- |
| Observation presented as a uniquely identified mechanism | Name the inference, alternatives, and discriminating evidence |
| Incompatible metrics treated as comparable | Restore definitions, conditions, and limits before comparison |
| Citation supports a related but different statement | Narrow the claim or find the correct located evidence |
| AI prose sounds certain without source support | Return it to the AI draft queue and verify or remove the assertion |
| Negative or contradictory evidence omitted | Include it and explain its effect on the argument |
| Strong design recommendation from limited conditions | Bound the recommendation to supported regimes and state tradeoffs |

<a name="section-5"></a>

## Peer-review-style checklist

- [ ] Every factual or quantitative statement has a checked source chain.
- [ ] Reported results, author interpretations, and my reasoning are distinguishable.
- [ ] Mechanism claims address alternatives, confounders, and identifiability.
- [ ] Conditions, units, uncertainty, and metric definitions are sufficient for comparison.
- [ ] Figures and tables have provenance, accurate captions, and justified processing.
- [ ] Negative findings, contradictions, and access limitations are visible.
- [ ] Conclusions match the evidence strength and scope.
