# Track D — LaTeX for Scientific Writing

> **Edition scope:** original AI-assisted supplement or study material. Some prerequisite lessons are withheld for source review; their titles are plain text, not unavailable links. [Attribution and scope](../SOURCES.md#pending).


> **Review status: framework.** Educational framework; this is not a record of learner progress. [Sources and limitations](../SOURCES.md).


Learn to prepare your own scientific text, equations, figures, tables, citations, and cross-references. Apply each exercise to a scientific writing task of your choice.

Use **Overleaf** as the suggested initial editor and PDF compiler. Start with a simple article and the [official introductory tutorial](https://www.overleaf.com/learn/latex/Learn_LaTeX_in_30_minutes). The tutorial is a reference to revisit, not a promise of mastery in 30 minutes. No local installation, community Obsidian plugin, or automatic Overleaf synchronization is required.

<a name="section-2"></a>

## Eight active learning weeks



| LaTeX week | Independent exercise | Output | Measurable completion check and after-help task |
| --- | --- | --- | --- |
| 1 — Document fundamentals | From a blank Overleaf article, identify preamble/body; add a title, two sections, and your own review question | First one-page PDF attempt | Compile, explain source versus PDF, then rename a section and recompile without copying the starter |
| 2 — Structure and paragraphs | Revise your own question, scope, and uncertainties; use paragraphs and section structure | One-page explanation of the review question in your own words | Explain document class, preamble, body, title, and sections; independently add and move a paragraph after any help |
| 3 — Scientific mathematics | Select a definition from a source you can check; typeset inline/display math, subscripts, and superscripts | Draft technical note on a selected hysteresis definition | Match every symbol to the checked source; define units, pressure range, and normalization; independently retype the expression after feedback |
| 4 — Numbering and references | Add a numbered equation, label, reference, and a second selected definition if verified evidence is available | Short technical note explaining the selected definition(s) and comparability limits | Equation references resolve; meaning, assumptions, units, and denominator remain unchanged; independently change a label and repair its references |
| 5 — MATLAB figure | Export one plot produced in the existing MATLAB session; insert it with a controlled width | Research note containing one documented MATLAB figure | Plot remains legible; axes and units survive export; state measured/published/digitized/synthetic provenance; independently change width and recompile |
| 6 — Captions and cross-references | Add a caption, label, reference, and suitable float placement; trace the plot to code and data | One properly documented MATLAB figure integrated into the note | Caption states conditions, data source, processing, and limitations; place the label after the caption; independently rename it and fix the reference |
| 7 — Tables and bibliography | Create a comparison table from checked evidence; add checked records to the bibliography starter and cite them | Table plus a developing verified bibliography | Preserve definitions/conditions and missingness; check each entry against its source; independently add a column or move a citation |
| 8 — Integrated short section | Assemble your own 2–3 page section with an explained equation, MATLAB figure, comparison table, and at least three independently verified references | Introductory competence milestone, with a claim/source audit | No unresolved citations or cross-references; three real checked references; independently make a small change in each element and explain it |

Use real verified literature only. If a definition, figure, or three checked references are unavailable, record the specific gap and retain an incomplete milestone. Continue available syntax practice using non-scientific text or a clearly marked blank table; never invent evidence. There is no requirement to finish unavailable scientific work by silently extending the weekly time budget.

<a name="section-3"></a>

## Milestone: formatting and scientific reasoning are separate checks

- [ ] A short 2–3 page document contains one explained equation, one MATLAB figure, one comparison table, and at least three independently verified references.
- [ ] References from the text to the equation, figure, and table work; citation keys resolve after recompilation.
- [ ] Symbols, units, assumptions, pressure ranges, and normalization conventions match the scientific analysis.
- [ ] Every figure states whether its data are measured, published, digitized, or synthetic teaching data; provenance and uncertainty/limitations are retained.
- [ ] Every scientific claim remains connected to its evidence and exact source location; unresolved verification flags survive typesetting.
- [ ] You can reproduce or modify the relevant syntax independently after assistance and explain the science separately from formatting.

This demonstrates introductory working competence, not LaTeX mastery. Defer custom classes, elaborate layouts, advanced drawing, and extensive macro design until needed. After the eight active weeks, use LaTeX inside normal writing/revision sessions. Consider a primary manuscript format only after the milestone; preserve a backup and avoid two independently edited manuscript versions. This task does not migrate or rewrite the full review.
