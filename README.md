## Read, attempt, then check

Work through a problem independently before opening its hints or worked solution. The assistance is kept in separate files, though GitHub search may reveal answers. Equations use native Markdown mathematics, and original SVG diagrams appear in the relevant section indexes.

This is a **selected educational collection**, not a complete lecture edition. Source-following lessons and dependent material awaiting attribution or redistribution review are withheld. Their absence is stated explicitly; Lectures 03 and 04 are not included.

The notes preserve their **unverified AI-assisted draft** status and scientific limitations. File completion does not establish scientific correctness or learner mastery. Hypothetical writing examples and calculated model plots are not experimental findings.

Read [Sources, attribution and edition scope](SOURCES.md) for the included question IDs, bibliographic references and exclusions. The retained Quartz license notice concerns the original template; no new blanket reuse license for the educational notes is granted here.
